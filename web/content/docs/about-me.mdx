## CppTorch — University Project

**CppTorch** is a minimal neural-networks library written in C++20 that I built as my university project. It provides numpy-style array primitives, dense layers, activations, losses, optimizers, and a complete training loop.

Key technical highlights:

- **Multithreaded architecture** — Element-wise kernels use OpenMP-parallel `parallel for simd` with size thresholds, so small buffers don't pay the thread-spawn cost.
- **OpenBLAS implementation** — Dense matrix products go through `cblas_dgemm`, with `dot_transpose_left` and `dot_transpose_right` variants that avoid materialising transposed copies, which matters for the backward pass.
